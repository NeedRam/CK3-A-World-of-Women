# Privacy

AWOW Universal Female Generation is an offline Crusader Kings III native mod
and installer. It does not collect, transmit, sell, or analyze personal data.
It has no analytics, advertising, telemetry, cookies, or hosted account.

The installer reads only the paths needed to find or validate a selected CK3
`binaries` directory and to maintain local UFG state, journal, quarantine, and
log files. These remain on the local computer. The installer does not upload
game files, saves, local paths, or logs.

Downloading a release or visiting the repository uses third-party web services
with their own privacy policies. Public GitHub release automation records build
provenance but does not receive local game data.
